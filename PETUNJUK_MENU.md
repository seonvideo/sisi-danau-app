# Pembaruan menu Sisi Danau

Versi ini menghilangkan menu **Bahan & Harga** dan **Resep & HPP** dari navigasi dan tampilan aplikasi. Tabel serta data lama di Supabase tidak dihapus.

## Cara menjalankan di Windows
1. Ekstrak ZIP ke folder baru.
2. Salin file `.env` dari proyek lama ke folder `download` ini (file `.env` tidak disertakan karena berisi konfigurasi pribadi).
3. Buka folder `download` ini di VS Code.
4. Di terminal VS Code, jalankan `npm.cmd install`.
5. Jalankan `npm.cmd run dev`.
6. Buka URL lokal yang ditampilkan Vite.

Menu yang tersedia: Dashboard, Stok Dapur, Stok Bar, Stok Service, Export & Cetak, dan Kas Harian.
